# Schedule-Optimizer
## Overview:
Smart Schedule Optimizer is a scheduling application that generates personalized daily schedules which also prioritizes productivity, health, and sufficient sleep.

Users provide their daily activities, fixed commitments, and sleep requirements. The system automatically creates an optimized timetable that helps with time management and also prevents unhealthy scheduling.

## Problem Statement:

Many people create schedules that focus only on completing tasks and often neglect:

Sleep schedule
Exercise
Meals
Rest breaks

This project aims to generate balanced schedules that improve productivity without having to sacrifice health and well-being.

## Objective

The primary objective of the Schedule Optimizer is to help users create a balanced and efficient daily timetable based on their personal requirements, priorities, and fixed commitments. The application aims to maximize productivity while ensuring that essential aspects of a healthy lifestyle, such as sufficient sleep, meal breaks, and short relaxation breaks, are not compromised.

By organizing tasks according to their importance, the system assists users in managing their day effectively, reducing scheduling conflicts, and promoting better time management habits.

## Scope

The Schedule Optimizer is designed as a personal productivity and time management tool for students, professionals, and individuals with busy daily routines. It allows users to input their sleep schedule, daily tasks, task durations, priorities, and special events to generate a structured timetable for the day.

The current scope of the project includes:

* Generation of a personalized daily schedule based on user inputs.
* Priority-based arrangement of tasks.
* Integration of fixed events such as classes, meetings, or appointments.
* Automatic inclusion of meal breaks and tea breaks to encourage healthy work habits.
* Protection of the user's sleep schedule by preventing task allocation during sleeping hours.
* A simple and user-friendly web interface built using HTML, CSS, and JavaScript.

## Features:

Sleep-hour protection

Daily schedule generation

Conflict-free task allocation

Priority-based scheduling

Deadline-aware planning
